# docs/

| Path | Owner | What goes here |
|---|---|---|
| `architecture/` | ARCHITECT | System design, data model, API contracts, ADRs, decisions |
| `design/` | DESIGNER | Flows, screen specs, states, visual system, copy, accessibility |
| *(everything else)* | DOCS | README, guides, reference, changelog, onboarding |

Subfolders are created when the first document lands in them.
